# 日常副本流程与故障修复

## 流程

1. 确认游戏已启动，关闭面板、离开旧队伍并检查血量。
2. 创建江湖纪事日常单人队伍，经活动面板进入日常副本。
3. 等待真实任务追踪确认入本。副本队伍栏使用左上方任务入口切换任务页签；不把选择页消失当作入本成功。
4. 点击副本追踪启动挂机，周期刷新，检测完成传出倒计时或稳定传出场景。
5. 完成后关闭奖励面板，点击退出与退本退队；验证副本控件消失且主场景稳定。已确认完成时允许等待自动传出，再确认残留队伍已清理。
6. 任务失败时先安全退本。常规清理失败才强制重启；重启后的离队可能触发过图，等待加载结束后重新打开队伍面板，以未组队按钮确认成功。
7. 队列仅在恢复成功后继续后续任务和角色；恢复失败保留断点并停止，不把未知现场当作恢复成功。

## 本次根因

- 副本队伍栏的任务入口未被旧模板覆盖，默认激活坐标没有切换到任务页签。
- 原退出图标在生产失败帧中得分 0.898764，低于 0.9；完成倒计时阶段另有不同外观。补充真实模板，保留阈值与限定区域。
- 重启后在副本中离队会传送金陵，原逻辑仅用 5 秒等待队伍面板按钮，误将加载画面判为恢复失败，导致整条队列终止。
